# INNOVEXA Premium Site

A premium Next.js website for INNOVEXA, an AI, design, automation, and digital growth studio. The site includes animated service sections, a 3D hero scene, pricing, portfolio highlights, testimonials, blog previews, and a contact intake form.

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Three.js with React Three Fiber and Drei
- GSAP and Framer Motion
- Lenis smooth scrolling
- EmailJS for contact form delivery

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the app at:

```text
http://localhost:3000
```

## Environment Variables

Copy `.env.example` to `.env.local` for local development. The same keys must be added in
Vercel → Project → Settings → Environment Variables for production.

```env
# Canonical production URL (no trailing slash) — used for metadata, OG, robots, sitemap.
NEXT_PUBLIC_SITE_URL=https://innovexadigital.in

# Contact form -> Google Sheet (server-side only). Apps Script Web App /exec URL.
GOOGLE_SHEET_WEBHOOK_URL=https://script.google.com/macros/s/XXXX/exec
```

The contact form stores submissions in a **Google Sheet** (no email is sent). It posts to the
`/api/contact` route, which forwards each submission to a Google Apps Script Web App that appends a
row. See [docs/google-sheets-setup.md](docs/google-sheets-setup.md) for the one-time setup. If
`GOOGLE_SHEET_WEBHOOK_URL` is not set, the form shows an error asking the visitor to email instead.
If `NEXT_PUBLIC_SITE_URL` is omitted on Vercel, the production deployment URL is used.

## Brand Icons

All app icons, the PWA manifest icons, and the social-share (Open Graph / Twitter) image are
generated by a single script:

```bash
npm run icons   # regenerate app/favicon.ico, app/apple-icon.png, public/icon-192.png,
                # public/icon-512.png, app/opengraph-image.png, app/twitter-image.png
```

- **`app/favicon.ico`** (browser tab) is built from `scripts/assets/favicon-source.png` — replace
  that file and re-run `npm run icons` to change the favicon. It is emitted as a proper multi-size
  ICO (16/32/48/64/128/256).
- **`apple-icon`, `icon-192`, `icon-512`** (iOS / Android / PWA) are rendered from the brand arrow
  mark on the dark theme background.

Next.js automatically wires these file-based icons into the document head, so the browser tab,
home screens, and link-share previews all resolve to the correct asset.

## SEO

The site ships with an enterprise-grade technical + on-page SEO foundation:

- **Structured data (JSON-LD)** in `lib/structured-data.ts`: `Organization`/`ProfessionalService`
  (NAP, areaServed, opening hours, contact point, `OfferCatalog` of all services), `WebSite`,
  `WebPage`, `FAQPage` (rich-result eligible), and `BreadcrumbList`. Linked by `@id` into one graph.
  Review/AggregateRating markup is intentionally omitted (first-party testimonials — see the note in
  that file) to stay within Google's review-snippet policy.
- **Metadata** (`app/layout.tsx` + per page): keyword/location-rich titles and descriptions,
  canonical URLs, Open Graph + Twitter cards, robots directives, and an optional Google Search
  Console verification tag via `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`.
- **`/robots.txt`** and **`/sitemap.xml`** are generated from `app/robots.ts` / `app/sitemap.ts`
  (stable, content-derived `lastmod`). All metadata resolves against `lib/site-config.ts`.
- **Performance / Core Web Vitals**: fonts are self-hosted via `next/font` (no render-blocking),
  AVIF/WebP image delivery, optimized source images (`npm run optimize:images`), and a non-priority
  navbar logo so the hero owns the LCP preload.

After deploying, submit the sitemap in Google Search Console and set up a Google Business Profile to
compete in the local Map Pack (schema alone does not feed it).

## Deployment (Vercel)

This app is a standard Next.js 15 App Router project and deploys to Vercel with zero extra config
beyond environment variables.

1. Push the repository to GitHub/GitLab/Bitbucket.
2. In Vercel, **Add New → Project** and import the repo. The framework auto-detects as **Next.js**
   (also pinned in `vercel.json`).
3. Add the environment variables from the section above (at minimum the EmailJS keys if you want
   form delivery).
4. Click **Deploy**.

Build settings (already configured): build command `next build`, install command `npm install`,
output handled by Next.js, Node `>=20` (`.nvmrc` / `package.json` engines). Security headers and a
disabled `x-powered-by` header are applied in `next.config.ts`; `robots.txt`, `sitemap.xml`, and
`manifest.webmanifest` are served automatically from the App Router.

To verify the production build locally before deploying:

```bash
npm run build
npm run start
```
